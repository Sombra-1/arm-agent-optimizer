# Final submission checklist

## Repository and documentation

- [ ] README reviewed on the public repository.
- [ ] Mermaid architecture diagram renders correctly.
- [ ] Installation commands tested from a clean virtual environment.
- [ ] Demo commands tested without model download or workflow dispatch.
- [ ] All screenshots are current and captions match the visible evidence.
- [ ] Repository visibility is correct.
- [ ] MIT license is present and linked.
- [ ] Documentation links resolve.
- [ ] Normal CI is green.
- [ ] Working tree is clean and `origin/main` matches local `main`.

## Devpost and Arm usage

- [ ] Devpost headline and one-line description are complete.
- [ ] Devpost text includes Inspiration, What it does, How it works, Arm usage,
      quality, architecture, challenges, accomplishments, learning, limitations,
      next steps, and Built with.
- [ ] Arm usage clearly explains native AArch64, Neoverse-N2, topology, memory,
      llama.cpp, and CPU inference.
- [ ] KleidiAI build evidence is distinguished from runtime activation.
- [ ] Native evidence is clearly separated from synthetic evidence.
- [ ] The 132-execution result is described as `no_eligible_candidate`, not a
      successful performance optimization.
- [ ] Limitations are disclosed.
- [ ] No unsupported speedup or production-optimality claim appears.

## Video and assets

- [ ] Final video is uploaded and publicly playable.
- [ ] Final video duration is three to five minutes.
- [ ] Audio and captions are reviewed.
- [ ] Backup recording is retained.
- [ ] Project thumbnail, screenshots, and captions are current.
- [ ] Synthetic screenshots keep visible synthetic labels.

## Privacy and integrity

- [ ] No secrets, tokens, authorization headers, cookies, or private keys appear.
- [ ] No private filesystem paths or private repository URLs appear.
- [ ] No raw model response or request body is published.
- [ ] Model weights and caches are absent.
- [ ] Native run IDs and metrics match `docs/FINAL_VALIDATION_REPORT.md`.
- [ ] Mistral is not described as a quality failure, OOM, RAM failure, or Arm incompatibility.
- [ ] Existing validation tag is unchanged.
- [ ] No GitHub release was created as part of documentation finalization.

## Submission

- [ ] Devpost preview reviewed on desktop and mobile widths.
- [ ] Repository URL verified.
- [ ] Video URL verified.
- [ ] License link verified.
- [ ] Final submission URL verified after publication.
- [ ] Submission confirmation or receipt saved.
