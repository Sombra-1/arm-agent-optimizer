# Video recording checklist

The final rendered video is published. This pre-recording checklist is retained
as a reusable production guide; its unchecked boxes are not outstanding release
work. Final artifact details and public links are in
[`video/README.md`](../video/README.md).

## Environment

- [ ] Terminal font is at least 18–20 px and readable at 1080p.
- [ ] Browser zoom is set so tables and diagrams remain legible.
- [ ] Display resolution and capture area are fixed before recording.
- [ ] Dark/light themes have sufficient contrast.
- [ ] Notifications, chat pop-ups, mail previews, and calendar alerts are disabled.
- [ ] Desktop and browser bookmarks expose no private information.
- [ ] Microphone input and system audio levels are checked.
- [ ] A ten-second audio test has been played back with headphones.

## Prepared material

- [ ] Commands from `docs/DEMO_SCRIPT.md` are prepared in a clean terminal.
- [ ] The virtual environment and dependencies are installed before recording.
- [ ] README, final validation report, native run, architecture, and license tabs are open.
- [ ] Existing evidence is loaded before recording; no long workflow is awaited.
- [ ] No live model download is planned.
- [ ] Synthetic screenshots retain visible synthetic labels.
- [ ] Native evidence is visibly labelled native.
- [ ] A backup route exists if the historical artifact or GitHub page is unavailable.

## Privacy and safety

- [ ] Shell history and scrollback contain no tokens or credentials.
- [ ] No raw API token, authorization header, cookie, SSH key, or environment dump is shown.
- [ ] No private filesystem path appears.
- [ ] No private repository URL or unrelated remote is shown.
- [ ] Model responses and request bodies are not displayed.
- [ ] Browser developer tools and password manager prompts are closed.
- [ ] GitHub account notifications and personal profile details are minimized.

## Claims

- [ ] The 132-execution run is called a completed native optimization workflow.
- [ ] `no_eligible_candidate` is explained as a safety outcome.
- [ ] The run is not called a successful performance optimization.
- [ ] No speedup percentage is stated.
- [ ] Qwen results match the final validation table.
- [ ] Mistral quality, OOM, RAM fit, and Arm compatibility remain unknown.
- [ ] KleidiAI build verification and unknown runtime activation are distinguished.
- [ ] Synthetic evidence is never presented as Arm or model performance.

## Final capture

- [ ] Final duration is less than three minutes, with a 2:50 target.
- [ ] Opening problem and closing value proposition are both present.
- [ ] Mouse movement and scrolling are deliberate.
- [ ] Text remains on screen long enough to read.
- [ ] No command fails or emits distracting private information.
- [ ] A backup recording is saved separately.
- [ ] Final video is watched end-to-end after export.
- [ ] Audio is synchronized and free of clipping.
- [ ] Captions/subtitles are reviewed where available.
- [ ] Uploaded video plays without authentication.
- [ ] Repository, validation, video, and submission links are tested.
